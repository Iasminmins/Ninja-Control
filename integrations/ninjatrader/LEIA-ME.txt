NINJA CONTROL - CONECTOR NINJATRADER 8 (SOMENTE LEITURA)

INSTALACAO EM QUALQUER PC WINDOWS COM NINJATRADER 8 DESKTOP

1. No Ninja Control, abra Integrações > NinjaTrader 8 Desktop e crie um token.
   Copie o token; ele só é mostrado uma vez.
2. No NinjaTrader, abra New > NinjaScript Editor.
3. Crie um AddOn chamado NinjaControlAddOn e cole o conteúdo de
   NinjaControlAddOn.cs no editor. Compile pelo próprio NinjaTrader.
4. No Control Center, abra New > Ninja Control - Iniciar sincronização
   somente leitura.
5. Informe o endpoint HTTPS e o token do workspace. Marque uma ou mais
   contas na lista e confira o modo: LIVE · CONTA REAL ou SIM · DEMONSTRAÇÃO.
6. No Ninja Control, associe a conta descoberta à conta correspondente.

SEGURANCA

- O AddOn permite sincronizar contas LIVE e Sim/demo do NinjaTrader.
- LIVE usa dinheiro real. Confira o rótulo da conta antes de iniciar.
- A credencial é protegida pelo Windows DPAPI para o usuário atual. Não copie
  settings.json entre PCs; configure o token de novo em cada computador.
- O arquivo de configurações fica em Documentos\NinjaTrader 8\NinjaControl.
- Cada instalação tem um identificador local; nomes iguais de contas em PCs
  diferentes aparecem separadamente para que você vincule cada uma.
- Todas as contas marcadas sincronizam simultaneamente; as escolhas ficam salvas
  neste usuário do Windows.
- A integração é somente leitura: não envia, altera, cancela ou liquida ordens.
- Use somente credencial do workspace e mantenha-a privada.

ARQUIVOS

- NinjaControlAddOn.cs: código-fonte do AddOn.
- LEIA-ME.txt: estas instruções.

A compilação do NinjaScript deve ocorrer no NinjaTrader instalado no PC de
destino, pois as bibliotecas da plataforma não acompanham este pacote.

DADOS AO VIVO

Ao iniciar, o AddOn captura saldo e métricas reportados pelo NinjaTrader, posições
abertas, ordens ativas e execuções disponíveis na sessão. Depois acompanha
alterações e envia novos snapshots a cada dois minutos. A tela informa se os
dados estão atuais, atrasados ou offline. Confira a janela Output do NinjaTrader
para ver erros HTTP de token, vínculo ou servidor. O histórico fica limitado aos
dados que a sessão atual do NinjaTrader mantém disponíveis.

Para atualizar uma instalação já rodando: substitua o código pelo
NinjaControlAddOn.cs deste pacote, compile no NinjaScript Editor e inicie a
sincronização novamente pelo Control Center. A instalação anterior não recebe
o código novo automaticamente.
